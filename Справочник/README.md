# Справочник

Исходные данные и справочные материалы со сроком годности: выписки из регламентов, инструкции, тарифы, условия договоров, схемы и порядки, которые верны только до определённого момента.

- Это не вечнозелёные знания: материал не переосмысливается, к нему обращаются как к данным.
- У каждой заметки поле `expires` во frontmatter — дата, после которой материал заведомо не нужен.
- Истёк срок — перемещай в `archive/`, а не удаляй. Что подходит к концу, показывает [Справочник — сроки](</dashboards/Справочник — сроки.base>).
- Материал, осмысленный только внутри проекта, держи в папке проекта, а не здесь.

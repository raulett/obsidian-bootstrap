# Save URL

Сохраняет веб-страницу заметкой в `inbox/` целиком: текст в markdown, картинки в `_files/`, frontmatter с источником, формат под правила линтера. Механику делает скрипт, ты — подбираешь теги и проверяешь результат.

## Шаги

1. **Подбери 1–3 тега** по заголовку и теме. Сначала словарь базы:

    ```bash
    .claude/skills/save-url/scripts/save_url.py --vocab
    ```

    Правило: хотя бы один тег из словаря, если там есть близкий по смыслу; новый тег — только когда тема в базе впервые. Двух точных тегов достаточно, третий «для количества» не нужен.

2. **Запусти скрипт** из корня хранилища:

    ```bash
    .claude/skills/save-url/scripts/save_url.py <URL> --tags тег1,тег2
    ```

    Полезные флаги: `--name` (своё имя заметки, если заголовок страницы плохой), `--force` (перезаписать, только по явной просьбе). Остальное — `--help`.

3. **Прочитай вывод**: путь заметки, число картинок, что не скачалось.
4. **Проверь заметку**: `head -15` — frontmatter, коллаут `[!info] Источник`, первый абзац — начало статьи, а не мусор навигации; `tail -5` — статья не оборвана и без хвоста комментариев/навигации. Сводка скрипта (заголовки, внешние картинки) закрывает проверку тела. Obsidian открыт → плагины допишут `created`/`updated`, не перезаписывай файл вслепую.
5. **Отчитайся**: путь, число картинок, проблемы (не скачавшиеся картинки, кривой заголовок).

## Что делает скрипт

- `defuddle parse --json --md` → текст, `title`, `author`, `published`, `og:site_name`.
- Имя заметки — из заголовка: `:` → ` — `, запрещённые в Obsidian символы убраны.
- Картинки: скачивает в `_files/<Имя заметки> — NN.<ext>`, ссылки переписывает в `![](</_files/…>)`. Не скачалось — оставляет внешнюю ссылку и пишет об этом.
- Нормализация под линтер: секции статьи сдвигаются так, что верхняя становится `#` — титульного заголовка у заметки нет, название живёт в коллауте (так устроены и остальные заметки базы); ёлочки → прямые кавычки, табы → 4 пробела, хвостовые пробелы и лишние пустые строки убраны. Содержимое код-блоков не трогает.
- Frontmatter: `tags`, `source`, `author`, `published` (дата). Коллаут: `[Заголовок](url) — Сайт, автор, дд.мм.гггг.` Сайт — из `og:site_name`, для известных доменов есть русское имя (`habr.com` → Хабр).
- В конце печатает сводку: число заголовков и их уровни, сколько внешних картинок осталось в тексте.
- Существующую заметку не перезаписывает (код выхода 2).

## Когда не подходит

- Ссылка на файл (`.md`, `.pdf`, картинка) — скачай `curl`ом в `_files/` и сделай заметку вручную.
- Страница требует логина или отдаёт 403 — `defuddle` не пройдёт; открой страницу через `claude-in-chrome` и сохрани текст руками, либо спроси владельца.
- Нужен не архив страницы, а конспект — используй `defuddle` и пиши заметку сам.

## Частые ошибки

- **Заметка уже есть** → скрипт вышел с кодом 2. Не добавляй `--force` сам: спроси, обновить ли.
- **Заголовок содержит имя сайта** («Статья / Хабр») или обрезан → задай `--name`.
- **Теги выдуманы заново** при наличии близких в базе → сначала словарь, потом `--tags`.
- **Скрипт запущен не из корня** → корень хранилища он находит сам по своему расположению, но `--out-dir`/`--files-dir` считаются от корня, а не от cwd.

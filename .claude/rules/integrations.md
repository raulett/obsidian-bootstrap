# Внешние интеграции: Nextcloud и Outline

Опциональные MCP-серверы поверх базы (`.mcp.json`) — канал агента к корпоративным системам. Оба инстанса **общие корпоративные**, поэтому данные в них — не только владельца. Доступны, **только пока подключены креды и сервер отвечает**; не подключены — спокойно пропусти (это не ошибка), работай базой и вебом.

- **`outline`** (`docs.softmus.ru`) — общая корп-вики: канонические знания компании (документы, коллекции).
- **`nextcloud`** (`home.softmus.ru`) — корп-облако: заметки, файлы (WebDAV), календарь и задачи, контакты, почта, чаты (Talk), доски Deck.

## Главное правило: по умолчанию только чтение

- **Читай свободно** — для контекста, поиска, подготовки заметок. **Не создавай, не меняй, не отправляй и не удаляй** ничего в этих системах по своей инициативе.
- **Запись — только по явной просьбе владельца.** Нет команды — режим read-only.
- Это **общие** системы: запись затрагивает не только владельца. Отправка письма (`nc_mail_send_message`), сообщение в Talk, приглашение в календарь, удаление или архивирование документа — outward-facing и трудно откатить. Даже по явной просьбе сначала покажи, **что именно** отправишь/изменишь/удалишь, и дождись подтверждения. Массовых рассылок и авто-отправки — никогда.
- Правило про внешние системы. Запись в **саму базу** по-прежнему идёт файлами (см. `CLAUDE.md`).

## Приоритет источников: внутреннее → веб

Прежде чем идти в веб, ищи во внутренних источниках по порядку — ответ часто уже внутри компании:

1. **Своя база** — `Grep` / omnisearch по vault.
2. **Outline** — корп-вики: `ask_ai_about_documents` (RAG ко всей вики), `search_documents`, `read_document`. Канонические знания компании.
3. **Nextcloud** — заметки и файлы: `nc_notes_search_notes`, `nc_webdav_search_files`.
4. **Веб** — скиллы ресёрча (`deep-research` и т.п.), когда внутри ответа нет.

Нашёл во внутреннем источнике — **сошлись на него** (укажи документ/файл), не пересказывай по памяти.

## Мост встреч: Calendar ↔ meetings/

- **Подготовка:** `nc_calendar_get_upcoming_events` / `nc_calendar_list_events` → заготовки заметок в `meetings/` (запись в базу файлами — ок, без подтверждения).
- **После встречи:** вынеси в заметку решения и action items как задачи `- [ ]`. Превращать их в todo/события Nextcloud или карточки Deck — внешняя запись: только по явной просьбе и с подтверждением.
- Контакты участников — обогащай заметку через `nc_contacts_search_contacts` (чтение).

## Карта «задача → сервер»

Дополнение к матрице в `tools.md` (доступно, только пока сервер подключён):

| Задача | Сервер / тулы |
|--------|---------------|
| Вопрос по знаниям компании | Outline: `ask_ai_about_documents`, `search_documents` |
| Найти/прочитать корп-документ | Outline: `read_document`, `read_document_section` |
| Ближайшие встречи, свободные слоты | Nextcloud: `nc_calendar_get_upcoming_events`, `nc_calendar_find_availability` |
| Заметки/файлы Nextcloud | Nextcloud: `nc_notes_search_notes`, `nc_webdav_search_files` |
| Контакты участников | Nextcloud: `nc_contacts_search_contacts` |
| Запись во внешнюю систему | только по явной просьбе + подтверждение |

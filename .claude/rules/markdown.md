# Форматирование Markdown в хранилище

Эти правила держат вывод Claude согласованным с тем, что навяжет `obsidian-linter`: он форматирует `.md` при сохранении и при изменении файла на диске, **пока Obsidian открыт**. Пиши сразу в этом виде — тогда повторный линт не даёт diff-шума (а `obsidian-git` коммитит автоматически), а при **закрытом** Obsidian (линтер не работает) формат всё равно остаётся корректным.

## Списки и выделение

- Маркеры ненумерованных списков — `-` (не `*` и не `+`).
- Жирный — `**текст**` (не `__`). Курсив — `*текст*`; не смешивай `*` и `_` для курсива в одном файле.
- Нумерованные списки — `1.`, `2.`, `3.` по возрастанию, с точкой после числа.
- Вложенность списков — отступ 4 пробела (Tab превратится в 4 пробела).
- Без пустых маркеров и без подряд идущих маркеров.

## Заголовки

- Инкремент по одному уровню: за `#` идёт `##`, не перескакивай (h2 → h4 запрещён).
- Без хвостовой пунктуации — символы `. , ; :` в конце заголовка срезаются.
- Каждый заголовок на своей строке. Регистр заголовков не навязывается.

## Пробелы, переносы, пустые строки

- Без хвостовых пробелов. Перенос строки двумя пробелами **не работает** (они вырезаются) — для нового абзаца ставь пустую строку.
- Подряд идущие пустые строки схлопываются до одной. Файл заканчивается одним переводом строки.
- Tab → 4 пробела; неразрывный пробел (nbsp) → обычный; несколько пробелов подряд → один.
- Пустая строка вокруг таблиц и горизонтальных линий `---`.
- Длину строк не ограничивай и не переноси прозу по ширине — лимита нет (`readableLineLength: false`).

## Цитаты, кавычки, код, ссылки

- Цитаты — `> ` с пробелом после `>`.
- Кавычки прямые: `"` и `'` (ёлочки и «кудрявые» нормализуются в прямые).
- Без «голых» URL: оформляй ссылкой `[текст](url)` либо `<url>`.
- Внутренние ссылки — стандартный Markdown, абсолютный путь от корня в угловых скобках с ведущим `/`: `[Текст](</Папка/Заметка.md>)`, вложения `![](</_files/файл.png>)`. Так их генерит `better-markdown-links` (дефолты) — пиши сразу в этом виде, иначе плагин нормализует и будет diff-шум. Не wikilinks (подробнее — в `CLAUDE.md`).
- Блоки кода — ограждённые тройными бэктиками; язык указывай по желанию.

## Frontmatter (YAML)

- `tags` и `aliases` — многострочным списком, не inline-массивом (конвенция единообразия; правило форматирования YAML-массивов в линтере сейчас выключено — стиль держит сам Claude):

  ```yaml
  tags:
    - foo
    - bar
  ```

- Поля дат `created` / `updated` ведёт плагин — руками не трогай (см. `CLAUDE.md`). Формат `yyyy-MM-dd'T'HH:mm:ss`.
- Порядок ключей frontmatter линтер не меняет — задавай как удобно.

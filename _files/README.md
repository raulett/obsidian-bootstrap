# _files — вложения

Хранилище вложений: картинки, PDF и прочие файлы, на которые ссылаются заметки.

- Папка скрыта в навигаторе и исключена из проверок ссылок.
- Вставляй вложения через интерфейс Obsidian — ссылки вида `![](_files/файл.png)` плагины проставят и починят сами. Раскладывать файлы здесь вручную обычно не нужно.

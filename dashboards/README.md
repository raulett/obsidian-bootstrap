# dashboards — сводные представления

Готовые представления [Bases](https://help.obsidian.md/bases) (`.base`) — динамические таблицы по всей базе.

- **Разбор инбокса** — очередь заметок из `inbox/` для регулярного разбора: возраст, источник, папка.
- **Активность** — недавняя активность по базе: новые и изменённые заметки за 30 дней.
- **Сроки** — всё хранилище: любая заметка с заполненным `expires`, независимо от папки и тегов. Виды: ближайшая неделя, ближайший месяц, просрочено, полный список. Сюда попадают и справочные материалы, и напоминания из проектов.
- **Справочник — сроки** — материалы со сроком годности из `Справочник/` и всё с тегом `type/reference`: что истекает в ближайший месяц, что просрочено, полный список со сроком. Заметки без заполненного `expires` (карты разделов, README) в сводку не попадают.

Открывай `.base` как обычную заметку. Это служебная папка представлений — обычные заметки сюда не клади.

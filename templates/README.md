# templates — шаблоны

Шаблоны заметок для быстрого создания однотипных записей (проекты, ресёрч и т.п.).

- Это служебная папка: обычные заметки сюда не клади.
- Плагин дат (`frontmatter-date-manager`) эту папку не трогает — плейсхолдеры и поля дат в шаблонах остаются как написано.

## Что здесь лежит

- `Заметка.md` — каркас обычной заметки: frontmatter с тегами, коллаут `[!summary]`, раздел "Связанные заметки".
- `Справочный документ.md` — каркас для раздела `Справочник/`: со сроком годности (`expires`) и тегом `type/reference`.
- `Шаблон канваса — поток мыслей.canvas` — образец для новых канвасов (`.canvas`, схемы и диаграммы на холсте Obsidian): несколько текстовых карточек, соединённых стрелками. Копируй его, когда начинаешь новую диаграмму или раскладываешь мысли по холсту, и заменяй текст карточек своим.

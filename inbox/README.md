# inbox — входящие

Посадочная папка для всего нового. Сюда складывай быстрый захват, неразобранные черновики и результаты ресёрча — не раскладывая сразу по местам.

Периодически разбирай `inbox/`: атомизируй, добавляй ссылки на связанные заметки и переноси по адресам:

- "вечнозелёное" → `Знания/` (в подпапку своей сферы)
- проектное → `Проекты/` (в папку проекта)
- замысел без срока → `Проекты/Когда-нибудь/`
- справочный материал со сроком годности → `Справочник/`
- устаревшее → `archive/`

Очередь разбора — в дашборде [Разбор инбокса](</dashboards/Разбор инбокса.base>).

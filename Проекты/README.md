# Проекты

Проектные заметки и материалы: всё, что относится к конкретной работе с целью и сроком.

- Каждый проект — своя подпапка, названная по имени проекта, с картой контента `Карта — Имя.md`.
- Держи рядом цели, статус, ссылки и связанные материалы проекта.
- Замыслы без срока — в `Когда-нибудь/`, по заметке на замысел.
- Когда проект завершён или заморожен — перемещай его в `archive/` целиком.

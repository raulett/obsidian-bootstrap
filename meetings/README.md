# meetings — встречи

Заметки встреч: повестка, участники, решения, договорённости и задачи по итогам.

- Создавай по заметке на встречу.
- Выводы и решения, которые переживут саму встречу, выноси отдельными заметками в `knowledge/` или `projects/` и связывай ссылками.

# knowledge — база знаний

Постоянная база знаний: атомарные "вечнозелёные" заметки — одна заметка про одну идею, написанная так, чтобы остаться полезной и через год.

- Связывай заметки между собой markdown-ссылками — граф знаний ценнее тегов и папок.
- Сюда попадает то, что вызрело и оформилось в `inbox/`, а не сырой захват.
